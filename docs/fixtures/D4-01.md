# Test Fixture D4-01: WhatsApp-style list (anonymized)
Source: a real 13-stop list. Names replaced with invented ones and every unit number changed; blocks, streets, postal codes and all formatting quirks kept, because those are what the parser is tested on. Raw input: `tests/fixtures/d4-01.txt`.

## Expected result
13 stops. 10 resolve by postal code. 3 have no postal code (543 CCK St 52, 401 Pandan Gardens, 570 Hougang St 51) and must resolve by block + street search, shown as "confirm address". 1 comment line ignored (shown to the user, never routed). 1 deadline captured.

## What it demands of the parser (M1)
| # | Pattern seen | Requirement |
|---|---|---|
| 1 | Postal written 7 ways: `S(540248)`, `(692128)`, `S270004`, `Singapore 122464`, `. 600274.`, `s120410`, `,530444` glued to the unit | Find any standalone 6-digit number, with or without S / Singapore / brackets, any case |
| 2 | No postal code on 3 of 13 stops | Fallback: OneMap address search on block + street; never drop the stop; flag for confirmation |
| 3 | Abbreviations: `cck`, `st`, `ave`, `rd`, `blk` | Singapore abbreviation dictionary (cck → Choa Chu Kang, amk, tpy, etc.) |
| 4 | Unit in different positions: after street, before street (`Blk 355 #03-127 Bukit Batok…`), after postal | Unit pattern `#fl-unit` anywhere in the stop's text; 2–4 digit unit numbers |
| 5 | Block suffix letters, either case: `128b`, `464B` | Keep the letter; normalise to upper case; never drop it silently |
| 6 | Name on its own line above the address; one stop with no name | Line before an address line = recipient; name optional |
| 7 | Bullets `*`, double spaces, blank lines as separators | Blank line = new stop; strip bullets |
| 8 | Comment line that is not a stop | Attach as a note or ignore; show to the user, never silently route |
| 9 | Deadline in free text: `Send by 1 PM (7 Nov)` | "by 1 PM" → latest arrival 13:00; date captured; may apply to several stops |
| 10 | Extra words inside the address: `Lobby Blossom Residences` | Kept as drop-off note; development name matched to gate record |
| 11 | Same first name on two stops (`Arun & Mei`, `Arun (AK)`) | Dedup on postal + unit only, never on name |
| 12 | 677723 Blossom Residences | Reference gated case: must route to the main gate on Segar Road |
| 13 | `128b Plantation Crescent` with postal 692128 | Geocoder must not alter the block letter or postal code (RouteXL changed it to 690128 without warning); mismatch = warning |

## Open question
Does "Send by 1 PM (7 Nov)" apply only to the first stop (blk 543) or to the whole list? Working rule: deadlines can apply to several stops.
